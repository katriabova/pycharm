# Проект: Виджет банковских операций

# Описание

Проект предназначен для обработки данных о банковских транзакциях. Включает функции фильтрации по статусу (EXECUTED,
CANCELED) и сортировки по дате.

# Инструкции по установке

1. Клонируйте репозиторий:
   `git clone https://github.com`
2. Рекомендуется использовать Python 3.10+ и виртуальное окружение.

# Зависимости

Для проверки кода и типизации используются:

- `flake8` — проверка стиля кода (PEP 8).
- `mypy` — проверка статической типизации.
