## Тестирование

Для запуска тестов используется библиотека `pytest`.

`python -m pytest`

## Модуль decorators

Модуль содержит универсальные декораторы для контроля работы приложения.

### Декоратор `log`

Автоматически регистрирует детали выполнения функций: время вызова, имя функции, аргументы, результат или информацию об
ошибках.

**Параметры:**

- `filename` (необязательный): путь к файлу для записи логов. Если не задан, логи выводятся в консоль.

**Примеры использования:**

1. **Логирование в консоль:**
   ```python
   @log()
   def my_function(x, y):
       return x + y
   
   my_function(1, 2)
   # Выведет: 2023-10-25 15:30:01 my_function ok
