# Виджет банка

## Тестирование

Для запуска тестов используется библиотека `pytest`.
Команда для запуска:
`python -m pytest`

### Покрытие тестами

Проект покрыт тестами на 100%. Отчет о покрытии доступен в папке `htmlcov/index.html`.

## Модуль Generators

Содержит функции-генераторы для эффективной обработки данных транзакций.

### Примеры использования:

- `filter_by_currency(transactions, "USD")` — фильтрация операций по валюте.
- `transaction_descriptions(transactions)` — получение описаний операций.
- `card_number_generator(start, stop)` — генерация номеров карт в заданном диапазоне.
