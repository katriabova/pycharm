## Тестирование

Для запуска тестов используется библиотека `pytest`.
Команда для запуска:
`python -m pytest`

### Покрытие тестами

Проект покрыт тестами на 100%. Отчет о покрытии доступен в папке `htmlcov/index.html`.

## Модуль generators

Модуль предназначен для эффективной обработки больших массивов транзакций с использованием генераторов Python. Это
позволяет экономить память, так как данные обрабатываются "лениво" (по одному элементу за раз).

### Основные функции

1. **`filter_by_currency(transactions, currency)`**
   Фильтрует список транзакций по заданному коду валюты (например, "USD"). Возвращает итератор.

   ```python
   usd_transactions = filter_by_currency(transactions_list, "USD")
