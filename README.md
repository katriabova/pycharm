# Виджет банка

## Тестирование

Для запуска тестов используется библиотека `pytest`.
Команда для запуска:
`python -m pytest`

### Покрытие тестами

Проект покрыт тестами на 100%. Отчет о покрытии доступен в папке `htmlcov/index.html`.

## Модуль Generators

Содержит генераторы для фильтрации транзакций и работы с номерами карт.

### Пример:

`list(card_number_generator(1, 3))` -> вернет список из 3-х отформатированных номеров.
